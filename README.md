# Onegin

Привет, эта замечательная программа поможет вам разнообразить свой однообразный литературный быт.

Как собрать программу?

Чтобы собрать и запустить мою программу на своем компьютере просто запустить build.bat (перед этим убедитесь, что на вашем устройстве установлен компилятор g++ (ну и что у вас не калькулятор еще)..

Программа считывает данные (например, ваше любимое произведение Пушкина) из файла in.txt (пока что файл с именно таким названием должен лежать в папке с вашим exe и содержать ваши любимые строчки) (TODO ввод) и записывает произведение перетасованное всеми возможными способами в файл out.txt

А именно — в три блока:

- AFTER_UP_BUBBLE_SORT — строки, отсортированные по алфавиту пузырьком (регистр и знаки препинания не учитываются)
- AFTER_DOWN_QSORT — строки, отсортированные в обратном порядке стандартным qsortom (сравнение идёт с конца строки)
- ORIG — исходный порядок строк, как в вашем файле

Пустые строки при чтении пропускаются, так что произведение станет чуть короче (но только визуально(а душа то осталась)))).

## Основные функции программы

Все функции программы можно разбить по способам их применения:

**Чтение файла**

- `calc_file_size` — узнаёт размер файла через `stat`, чтобы сразу выделить нужный буфер. (использует <sys/stat.h>)
- `read_file_from_buffer` — открывает файл, читает его целиком в одну большую строку `text`, ставит `\0` в конец и бежит отдыхать (делать лабы по физике, конечно).
- `count_lines` — считает количество строк по символам `\n`, при этом подряд идущие переводы строки не создают пустых строк.
- `split_into_lines` — создает массив из указателей на места в `text` где лежат непустые строчки.
